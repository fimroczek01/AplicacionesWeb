Preguntas frecuentes

¿Qué es HTML?

HTML es un lenguaje que se utiliza para estructurar el contenido de la web

¿Qué es CSS?

Es el lenguaje estándar utilizado para definir la presentación visual de documentos estructurados en HTML o XML.
